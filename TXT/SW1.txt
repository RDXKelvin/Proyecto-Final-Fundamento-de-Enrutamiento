Objetivo del dispositivo:
Actuar como Switch Multicapa de Distribución/Core para su segmento de red. Se encarga de la creación de las VLANs, la configuración de las interfaces virtuales (SVIs) para actuar como Gateway, el reenvío de peticiones DHCP (DHCP Relay) hacia el servidor central, y la agrupación de enlaces mediante EtherChannel LACP. También maneja el enrutamiento hacia el router principal.

Proceso de configuración:
! 1.1 Entrada al modo privilegiado y configuración global
enable
configure terminal

! 1.2 Identificación y mensaje de seguridad (Banner MOTD)
hostname SMC1
banner motd #SOLO PERSONAL AUTORIZADO Kelvin De Jesus Luna 2025-2144#

! 1.3 Seguridad de acceso y administración local
enable secret Cisco123
service password-encryption
username Admin privilege 15 secret Cisco123
username 2025-2144 privilege 15 secret Cisco123

! 1.4 Configuración del servicio SSH seguro
ip domain-name itla.local
crypto key generate rsa general-keys modulus 1024
ip ssh version 2
line vty 0 4
 login local
 transport input ssh
exit

! 1.5 Habilitación de enrutamiento IP y creación de VLANs
ip routing
vlan 2
 name SERVIDORES
vlan 3
 name EMPLEADOS
vlan 4
 name FINANZAS
vlan 5
 name TI
vlan 6
 name WIFI
vlan 7
 name NATIVA
exit

! 1.6 Configuración de SVIs (Gateways) y reenvío DHCP
int vlan 2
 ip add 21.44.74.129 255.255.255.128
 ip helper-address 21.44.75.97
 no sh
int vlan 3
 ip add 21.44.74.1 255.255.255.224
 ip helper-address 21.44.75.97
 no sh
int vlan 4
 ip add 21.44.75.1 255.255.255.224
 ip helper-address 21.44.75.97
 no sh
int vlan 5
 ip add 21.44.75.65 255.255.255.224
 ip helper-address 21.44.75.97
 no sh
int vlan 6
 ip add 21.44.72.1 255.255.254.0
 ip helper-address 21.44.75.97
 no sh
exit

! 1.7 Enlace punto a punto enrutado L3 hacia R3-DHCP
int gig1/1/1
 no switchport
 ip add 21.44.75.98 255.255.255.252
 no sh
exit

! 1.8 Configuración de EtherChannel LACP y troncal hacia SW3
int port-channel 2
 sw mo tru
 sw tru native vlan 7
 sw tru allowed vlan 2,3,4,5,6,7
 sw nonegotiate
 no sh
int ra gig1/0/22-23
 sw mo tru
 sw tru native vlan 7
 sw tru allowed vlan 2,3,4,5,6,7
 sw nonegotiate
 channel-group 2 mode active
exit

! 1.9 Troncal hacia switch de acceso inalámbrico SW4
int gi1/0/24
 sw mo tru
 sw tru native vlan 7
 sw tru allowed vlan 6,7
 sw nonegotiate
 no sh
exit

! 1.10 Ruta por defecto hacia R3-DHCP y guardado
ip route 0.0.0.0 0.0.0.0 21.44.75.97
end
wr
